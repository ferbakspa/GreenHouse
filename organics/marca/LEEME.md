# Marca Organics One

Logo oficial del producto: un brote con la señal wifi. Lo mantiene el proyecto de hardware. La app lo usa tal cual, sin redibujarlo ni cambiarle los colores.

| Archivo | Uso |
|---|---|
| `organics_one_isotipo.svg` / `.png` | Solo el símbolo: ícono de la app, favicon, avatar |
| `organics_one_logo_texto_oscuro.svg` / `.png` | Logo con texto para fondos claros |
| `organics_one_logo_texto_claro.svg` / `.png` | Logo con texto para fondos oscuros |
| `organics_one_equipo.png` | Imagen del Gateway, fondo transparente (pantalla de inicio, conexión de la tarjeta) |

Los PNG tienen fondo transparente. Los SVG tienen el texto convertido a trazos, así que no necesitan la fuente.

## Colores

| Color | HEX | Uso |
|---|---|---|
| Verde planta | `#3FB24A` | Planta del logo |
| Naranjo AIDEX | `#EC7D37` | Señal wifi, acentos, alertas suaves |
| Calipso AIDEX | `#26A5CD` | Acentos, estado "encendido" |
| Gris AIDEX | `#8C8F90` | Textos secundarios |
| Grafito | `#3A3E44` | Fondos oscuros, textos sobre fondo claro |

Tipografía del logo: Orbitron (Google Fonts, licencia OFL).

## Reglas

- Nunca escribir "AIDEX" solo. Usar siempre **AIDEX Technologies**, o **AIDEX Tech** si no cabe.
- No deformar el logo, no cambiar sus colores y no agregarle efectos.
